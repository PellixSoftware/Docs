# d3d11

**Note: This is primarily for advanced users which are willing to use native D3D11 features via FFI.**



{% code overflow="wrap" %}
```luau
d3d11.get_device(): uintptr_t
```
{% endcode %}

Get address of the [ID3D11Device](https://learn.microsoft.com/en-us/windows/win32/api/d3d11/nn-d3d11-id3d11device).



{% code overflow="wrap" %}
```luau
d3d11.get_device_context(): uintptr_t
```
{% endcode %}

Get address of the [ID3D11DeviceContext](https://learn.microsoft.com/en-us/windows/win32/api/d3d11/nn-d3d11-id3d11devicecontext).
